# v1 launch audit — 2026-11-02

Ankka is close to shippable. The data layer is careful and well tested, the code has no TODOs, force-`try`s or `fatalError`s, and Release builds succeed. Before submitting, fix five things: the Free/Pro gate holes, the missing card delete/rename on iOS, the outdated live privacy policy, the app icon's alpha channel, and an uncommitted working tree. The rest is bug fixing and polish, ordered below.

This pass is audit and plan only. No app code was changed. One temporary probe test was added to confirm findings, then removed.

## Baseline and verification

- Branch `release/app-store` @ `ab3a733` (0.9.9 build 113). The working tree also has **uncommitted Demo-build work** (see B1).
- iOS unit tests: **285 run, 0 failures, 5 skipped** (StoreKit cases need a team-signed build). Simulator iPhone 17, iOS 26.5, Xcode 27.2.
- iOS UI tests: see "UI test run" at the end.
- iOS Release build (generic device, unsigned): **succeeds**, 5 warnings. Mac Release build: **succeeds**, 4 Swift 6 isolation warnings.
- Server (`server/ankka-chat`): 7 vitest tests pass, `tsc --noEmit` clean. Haiku 5.5 prices in `usage.ts` ($0.10 / $0.50 per MTok, $0.50 / $2.50 above 100K) match Anthropic's current price list, so the $1 per user and $25 global caps are correct.
- Live endpoints: privacy page, support page, `/health` and `/v1/roadmap` return 200.
- Confirmed by a probe test (removed afterwards): the Sample card stays on Home after "Keep the Sample card" is turned off; a Free workspace can add stacks and stack caps through Manage Stacks; CSV import succeeds on Free; the fallback notice reads "…Try again in a moment.. Answered by Apple Intelligence…"; SGD/MYR/THB/CHF amounts print as "SGD12.50" with no space.
- Not verified: anything that needs a device or a paid account (Face ID, StoreKit sandbox, App Group widgets, Control Center, notifications). Items that depend on these are marked **verify on device**.

Severity: **P0** blocks submission, approval or revenue · **P1** broken feature or wrong result users will hit · **P2** UX/UI/AI improvement worth doing for 1.0 · **P3** cleanup or post-launch.
